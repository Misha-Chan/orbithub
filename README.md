# 🔒 صفحة خطأ 403 - ممنوع الدخول

صفحة خطأ 403 جميلة وعصرية باللون البني والذهبي والأسود، تحتوي على نموذج Three.js تفاعلي ثلاثي الأبعاد.

## 🎨 المميزات

- **تصميم عصري** بالألوان البنية والذهبية والسوداء
- **نموذج Three.js** تفاعلي (درع محظور + جسيمات + حطام فضائي)
- **تأثيرات حركية** سلسة مع تفاعل الماوس
- **تصميم متجاوب** يعمل على جميع الأجهزة
- **خط عربي** جميل (Tajawal)
- **تأثير Grain** أنيق للخلفية

## 📁 هيكل الملفات

```
error403-project/
├── public/
│   ├── index.html      # الصفحة الرئيسية
│   ├── style.css       # التنسيقات
│   └── script.js       # Three.js + animations
├── server.js           # خادم Express
├── package.json        # تبعيات Node.js
├── vercel.json         # إعدادات Vercel
└── README.md           # هذا الملف
```

## 🚀 التشغيل محلياً

```bash
npm install
npm start
```

## 🌐 النشر على Vercel

1. ارفع المشروع على GitHub
2. اربط المستودع بـ Vercel
3. اضبط إعدادات البناء على Node.js
4. انشر!
